# 🚀 GUÍA RÁPIDA - CÓMO INICIAR INVENTARIO FUXION CASA

## 📋 **MÉTODOS DE INICIO DISPONIBLES**

### **🖱️ SÚPER FÁCIL (Recomendado para la familia)**

1. **Hacer doble clic en:**
   ```
   🏢 INICIAR-INVENTARIO.bat
   ```
   - ✅ Se abre automáticamente el navegador
   - ✅ Muestra las credenciales de usuarios
   - ✅ Instala dependencias si es necesario

2. **Crear acceso directo en escritorio:**
   ```
   🖱️ Doble clic en: crear-acceso-directo.bat
   ```
   - ✅ Crea icono en el escritorio
   - ✅ Un solo clic para iniciar desde cualquier lugar

### **⚡ COMANDOS RÁPIDOS**

#### **PowerShell (Método alternativo):**
```powershell
.\inicio-rapido.ps1
```

#### **Línea de comandos tradicional:**
```cmd
npm run dev
```

### **🔄 INICIO AUTOMÁTICO CON WINDOWS**

Para que se inicie automáticamente cuando prendas la computadora:

1. **Ejecutar:**
   ```
   🖱️ Doble clic en: configurar-inicio-automatico.bat
   ```
2. **Confirmar con "S"**
3. **¡Listo!** Se iniciará automáticamente con Windows

## 🌐 **ACCESO A LA APLICACIÓN**

Después de iniciar, abre tu navegador en:
```
http://localhost:3000
```

## 🛑 **CÓMO DETENER LA APLICACIÓN**

- **Presionar:** `Ctrl + C` en la ventana negra
- **O cerrar** la ventana del terminal

## 🔧 **SOLUCIÓN DE PROBLEMAS**

### **❌ "Node.js no encontrado"**
- **Descargar:** https://nodejs.org
- **Instalar** y reiniciar la computadora

### **❌ "Puerto 3000 en uso"**
- La aplicación usará puerto 3001 automáticamente
- **URL será:** http://localhost:3001

### **❌ "Error de dependencias"**
- **Ejecutar:** `npm install` en la carpeta del proyecto
- **O usar:** INICIAR-INVENTARIO.bat (lo hace automáticamente)

## 📱 **ACCESO DESDE OTROS DISPOSITIVOS**

Para acceder desde celular/tablet en la misma red WiFi:
```
http://192.168.18.89:3000
```
*(La IP exacta se muestra al iniciar)*
