## 🌐 ALTERNATIVA: NETLIFY (También GRATIS)

### **📋 Pasos para Netlify:**
1. **Subir a GitHub** (mismo proceso que Vercel)
2. **Ir a:** https://netlify.com
3. **Registrarse** con GitHub
4. **New site from Git** → Seleccionar tu repo
5. **Deploy settings:**
   - Build command: `npm run build`
   - Publish directory: `.next`
6. **Deploy site**

### **✅ Resultado:**
- URL: `https://inventario-fuxion-casa.netlify.app`
- Disponible 24/7
- Mismo rendimiento que Vercel
